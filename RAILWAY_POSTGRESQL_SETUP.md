# 📘 Как добавить PostgreSQL на Railway

## Пошаговая инструкция

### Шаг 1: Откройте ваш проект на Railway

1. Зайдите на [railway.app](https://railway.app)
2. Войдите в свой аккаунт
3. Откройте ваш проект (приложение Django)

### Шаг 2: Добавьте PostgreSQL сервис

1. В вашем проекте нажмите кнопку **"+ New"** (справа вверху или внизу)
2. В выпадающем меню выберите **"Database"**
3. Выберите **"Add PostgreSQL"**

### Шаг 3: Railway автоматически настроит все

После добавления PostgreSQL:
- ✅ Railway автоматически создаст базу данных
- ✅ Railway автоматически установит переменную окружения `DATABASE_URL`
- ✅ Ваше приложение автоматически подключится к PostgreSQL

**Важно:** Вам НЕ нужно вручную устанавливать `DATABASE_URL` - Railway делает это автоматически!

### Шаг 4: Выполните миграции

После того, как Railway добавит PostgreSQL и перезапустит приложение:

1. Откройте ваш проект на Railway
2. Перейдите в раздел **"Deployments"** (или найдите кнопку **"View Logs"**)
3. Найдите кнопку **"Open Console"** или **"Shell"**
4. В консоли выполните:

```bash
python manage.py migrate
```

Это создаст все необходимые таблицы в PostgreSQL.

### Шаг 5: Создайте суперпользователя (опционально)

Если нужно создать администратора:

```bash
python manage.py createsuperuser
```

## ✅ Проверка

После выполнения миграций:

1. Откройте ваше приложение в браузере
2. Попробуйте зарегистрироваться или войти
3. Создайте тестового ученика
4. Если все работает - PostgreSQL настроен правильно!

## 🔍 Как проверить, что используется PostgreSQL

В логах Railway вы увидите что-то вроде:
```
Operations to perform:
  Apply all migrations: admin, auth, contenttypes, main, sessions
Running migrations:
  Applying main.0001_initial... OK
  ...
```

Если миграции выполняются без ошибок - все работает!

## ⚠️ Важные замечания

1. **Не удаляйте SQLite файл** (`db.sqlite3`) из проекта - он нужен для локальной разработки
2. **Не устанавливайте `DATABASE_URL` вручную** - Railway делает это автоматически
3. **Данные из SQLite не переносятся автоматически** - если нужно, сделайте дамп и импорт вручную

## 🆘 Если что-то пошло не так

### Проблема: Railway не связал PostgreSQL с приложением автоматически

**Как проверить:**
1. Откройте ваш проект на Railway
2. Перейдите в **Settings** → **Variables** (или **Environment Variables**)
3. Проверьте, есть ли переменная `DATABASE_URL`

**Если `DATABASE_URL` отсутствует - свяжите вручную:**

#### Вариант 1: Связать сервисы через UI Railway

1. В вашем проекте на Railway вы увидите два сервиса:
   - Ваше Django приложение
   - PostgreSQL база данных

2. **Способ A (через настройки PostgreSQL):**
   - Кликните на сервис PostgreSQL
   - Перейдите в **"Variables"** или **"Connect"**
   - Найдите переменную `DATABASE_URL` или `POSTGRES_URL`
   - Скопируйте её значение

3. **Способ B (через настройки приложения):**
   - Кликните на ваше Django приложение
   - Перейдите в **Settings** → **Variables**
   - Нажмите **"+ New Variable"**
   - Имя: `DATABASE_URL`
   - Значение: скопируйте из PostgreSQL сервиса (см. Способ A)

#### Вариант 2: Получить DATABASE_URL из PostgreSQL сервиса

1. Откройте сервис PostgreSQL в Railway
2. Перейдите в раздел **"Variables"** или **"Connect"**
3. Найдите переменную с именем:
   - `DATABASE_URL` или
   - `POSTGRES_URL` или
   - `PGDATABASE` + `PGHOST` + `PGPORT` + `PGUSER` + `PGPASSWORD`

4. Если есть `DATABASE_URL` - скопируйте её полностью
5. Если есть отдельные переменные, создайте `DATABASE_URL` в формате:
   ```
   postgresql://PGUSER:PGPASSWORD@PGHOST:PGPORT/PGDATABASE
   ```

6. Добавьте эту переменную в настройки вашего Django приложения:
   - Откройте Django приложение → **Settings** → **Variables**
   - Нажмите **"+ New Variable"**
   - Имя: `DATABASE_URL`
   - Значение: вставьте скопированную строку
   - Сохраните

7. **Перезапустите приложение:**
   - Railway автоматически перезапустит приложение после изменения переменных
   - Или вручную: **Settings** → **Redeploy**

#### Вариант 3: Использовать Railway CLI

Если у вас установлен Railway CLI:

```bash
# Получить переменные PostgreSQL
railway variables --service <postgres-service-id>

# Установить DATABASE_URL в приложении
railway variables set DATABASE_URL=<значение> --service <django-service-id>
```

### Проблема: Приложение не подключается к PostgreSQL

**Решение:**
1. Проверьте, что PostgreSQL сервис добавлен
2. Проверьте переменные окружения - должна быть `DATABASE_URL`
3. Проверьте логи Railway на наличие ошибок подключения
4. Убедитесь, что оба сервиса находятся в одном проекте Railway

**После ручной настройки `DATABASE_URL`:**

1. Проверьте логи приложения - должны исчезнуть ошибки подключения к базе
2. Выполните миграции через консоль Railway:
   ```bash
   python manage.py migrate
   ```
3. Если миграции выполняются успешно - все работает!

**Как проверить, что используется PostgreSQL:**

В консоли Railway выполните:
```bash
python manage.py dbshell
```

Если вы видите приглашение PostgreSQL (например, `postgres=#`) - все работает правильно!

### Проблема: Ошибка "dj_database_url not found"

**Решение:**
Убедитесь, что в `requirements.txt` есть:
```
dj-database-url==2.1.0
psycopg2-binary==2.9.9
```

Затем перезапустите деплой на Railway.

### Проблема: Миграции не выполняются

**Решение:**
Выполните миграции вручную через консоль Railway:
```bash
python manage.py migrate
```

## 📝 Дополнительная информация

- Railway предоставляет бесплатный тариф для PostgreSQL (с ограничениями)
- База данных автоматически резервируется
- При удалении проекта база данных также удаляется
- Для продакшена рекомендуется использовать платный тариф Railway для большей надежности
