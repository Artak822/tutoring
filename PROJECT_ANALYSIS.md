# Анализ CRM-системы для репетиторства

## Стек
Django + SQLite (Railway PostgreSQL в проде)

## Что уже есть

### Модели
- `Tutor` — профиль репетитора
- `Student` — ученик (имя, телефон, telegram, класс, заметки, баланс предоплаты)
- `StudentGroup` — группы учеников
- `Lesson` — занятие (дата, время, длительность, цена, предмет, заметки)
- `Attendance` — посещаемость (present/absent, notes)
- `Payment` — оплата (наличные/перевод/баланс предоплаты, флаг is_balance_payment)

### Функционал
- Календарь (месячный + недельный для мобилки)
- CRUD: ученики, занятия, группы
- Отметка посещаемости с автоматическим списанием предоплаты
- Повторяющиеся занятия (еженедельно, период до 1 года)
- Дашборд: кол-во учеников, прибыль за неделю/месяц/всё время, топ должников
- Отчёт по прибыли за период (по дням, по ученикам, по способу оплаты)
- Список всех долгов + погашение всех долгов ученика разом
- Регистрация/вход
- **Быстрое закрытие занятия** — посещаемость и оплата прямо на странице занятия без переходов (AJAX)

### Быстрое закрытие занятия (quick-close)
Реализовано в ветке `feature/quick-close-lesson`.

**Логика:**
- На странице занятия для каждого ученика — сегментный переключатель «Пришёл / Не пришёл»
- При отметке «Пришёл»: система автоматически проверяет предоплату и списывает, если достаточно
- Если предоплаты нет — появляется форма с полем суммы и кнопками оплаты (наличные / карта)
- Сумма больше цены занятия → излишек уходит на предоплату
- Кнопка сброса удаляет оплату (с возвратом на баланс, если было автосписание)
- Статистика «Присутствовало» и «Общая стоимость» обновляется без перезагрузки страницы

**Изменённые файлы:**
- `main/views.py` — новый endpoint `quick_lesson_action` + вспомогательная функция `_payment_to_dict`; обновлён `lesson_detail` (добавлен `students_state_json` в контекст)
- `main/urls.py` — маршрут `lesson/<lesson_pk>/quick-action/<student_pk>/`
- `main/templates/main/lesson_detail.html` — полная переработка секции посещаемости: JS-рендеринг состояний, AJAX, анимации, сегментные кнопки, мобильная вёрстка

**Список учеников:**
- Карточка ученика теперь показывает предоплату (`Предоплата: X ₽`, зелёный badge), если долгов нет, но есть баланс
